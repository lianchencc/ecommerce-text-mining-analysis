# E-commerce Text Mining & Sales Trend Analysis

A text mining and data analysis project using Python to analyze
customer comments and e-commerce product trends.

## Overview

This project analyzes e-commerce customer comments and product
sales data to identify product-related discussions, customer
sentiment, and category-level sales trends.

## Objectives

- Identify customer comments related to specific products
- Analyze customer sentiment from product-related comments
- Explore sales trends across different product categories

## Technologies

- Python
- Pandas
- Jieba
- SnowNLP
- Matplotlib
- Jupyter Notebook

## Analysis Process

### 1. Data Preprocessing

- Removed irrelevant and advertising comments
- Cleaned customer comment data

### 2. Product-related Comment Analysis

Used Jieba for Chinese word segmentation and POS tagging
to extract product-related nouns.

### 3. Sentiment Analysis

Used SnowNLP to calculate sentiment scores for
product-related comments.

### 4. Sales Trend Analysis

Grouped product sales data by category and month
to visualize changes in sales volume over time.

## Results

The analysis visualizes:

- Customer sentiment toward products
- Monthly sales trends by product category
- Differences in category-level sales performance
